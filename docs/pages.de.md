# Seiten (Menü)

| Seite | Zweck |
|-------|--------|
| **All cables** | Gefilterte Tabelle, Längensumme, Listen kopieren, Export |
| **Stopped cables** | Aktuelle Stopps nach Endsegment, Restmeter, Export |
| **Stütze / Bahn szűrő** | Stütze-/Bahn-Nummern einfügen; AND/OR; Export |
| **Cable ID export** | IDs einfügen (`;`); Duplikate entfernen; CaTra / Kurzliste |
| **Areas** | Raumfortschritt & Schätzung — **[estimation.de.md](estimation.de.md)** |
| **Workforce** | Tagesstärke nach Position, Diagramme |
| **Nyomvonal-csoportok** | Ähnliche Pfade (~90 %) |
| **Progress** | Tägliche / wöchentliche (KW) verlegte Meter |
| **Hibák** | Abweichungen Progressliste ↔ Gesamtliste |
| **Hossz kalkulátor** | Teillänge entlang des Pfads |
| **Hogyan működik** | Kurze In-App-Hilfe |

Überblick: [overview.de.md](overview.de.md).
